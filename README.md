# Preveseg - Plataforma de Seguridad Industrial y EPP

Plataforma web de alta tecnología para la exhibición, cotización e inventario de equipos de protección personal (EPP), seguridad industrial, dotaciones y señalización.

## 🚀 Características Principales

- **Identidad Visual Oficial Dual**: Equilibrio de marca con Azul Real Industrial (`#0066ff`) y Rojo Fuego de Extinción (`#ee1b24`).
- **Catálogo de Productos y Ofertas**: Vista rápida, filtrado por categorías, búsqueda en tiempo real, carrusel de productos destacados y ficha técnica.
- **Cotización Directa por WhatsApp**: Integración con mensajes personalizados y enlace directo a asesor comercial (`+57 3046296285`).
- **Panel de Administración Móvil-First (`/Admin_panel`)**:
  - Gestión completa de inventario (creación, edición, visibilidad y destacado de productos).
  - Gestor de imágenes con vista previa inmediata y eliminación táctil.
  - Generador de Fichas y Cartas QR personalizadas para entrega física.
  - Estadísticas dinámicas de inventario y suscriptores de boletín.
- **Base de Datos Supabase**: Sincronización en tiempo real de productos, variantes, categorías y suscriptores.

## 🛠️ Tecnologías

- **Frontend**: React 18 + TypeScript + Vite
- **Estilos**: CSS3 Moderno con Glassmorphism y diseño responsivo móvil
- **Iconos**: Lucide React
- **Base de Datos & Backend**: Supabase (PostgreSQL)

## 📦 Instalación y Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
